# Product

## Users

Vietnamese-speaking developers reviewing programming topics and work-related English.

## Product Purpose

Bovabon Edu is a Vietnamese-language learning management system for reviewing programming and IT English through learning tracks, quizzes, and automatically graded coding exercises.

## Operating Context

Users do not need to sign in. Learning progress is stored locally.

## Capabilities and Constraints

- Provides programming learning tracks.
- Automatically grades coding exercises.
- Stores progress locally without an account.
